第16章演示导航

场景：外卖配送进度（SSE）→ 回声入门（WebSocket）→ 客服一对一（WebSocket）→ STOMP 群聊（进阶）。演示页用 Vue 3 CDN，无需构建。启动模块后点开对应页面即可。

SSE · 单向推送

外卖订单配送

模拟订单从下单到送达的状态流，浏览器用 EventSource 收推送。

 WebSocket · 入门

回声 Echo

发一句，回一句。先搞懂握手、收发、断开。

 WebSocket · 业务

客服一对一

1 顾客 + 1 客服，纯文本互转。对照后端两个 session 字段即可读懂。

 STOMP · 进阶

主题群聊

SockJS + STOMP：订阅 /topic/chat，发送 /app/chat.send。
